# TK-Coach 2.0 — Pitch-Website (Pilawa Film × Cyber Health)

Die Pitch-Website für die Videoproduktion der TK-Coach 2.0 Empowerment-Programme.

**Live ansehen:** https://tk-coach-pitch.vercel.app

## So bearbeitest du die Website
Die ganze Website steckt in **einer einzigen Datei**: `index.html`.
Alle Bilder und das Video liegen im Ordner `assets/`.

Du musst den Code **nicht selbst** verstehen oder anfassen. Sag einfach
**Claude** in normalem Deutsch, was du ändern möchtest — Claude kümmert sich um den Rest.

Eine ausführliche Schritt-für-Schritt-Anleitung hast du per E-Mail als PDF ("Schritt 2") bekommen.
